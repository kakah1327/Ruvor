# D-25 — Rebrand para Ruvor em toda a superficie

**Status:** aceita · 2026-08-29

## Contexto

O nome esta decidido (D-01) e a estrutura do repositorio vai mudar completamente.

## Decisão

**Ruvor substitui VaR Lab em tudo.** A estrutura nova nasce com os nomes certos; o prototipo nao e renomeado.

## Consequências

- Renomear dentro da estrutura velha seria refazer o mesmo trabalho duas vezes.
- Superficie: repositorio, pacote (`varlab/` -> `engine/`), comando (`varlab run` -> `ruvor run`), diretorio de dados (`~/.varlab/` -> `~/.ruvor/`), variaveis de ambiente (`VARLAB_*` -> `RUVOR_*`), documentacao, frontend e o texto do TCC.
- A verificacao de marca e dominio segue pendente, em paralelo.
