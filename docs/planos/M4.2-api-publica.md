## Como ler este plano

[PROCESSO §5](../PROCESSO.md#5-anatomia-de-um-plano): contratos, não corpos. Literal só onde é
contrato (assinaturas, `db_table`, colunas, configurações, nomes) ou onde a falha é silenciosa
(o gerente que falha fechado, o zerar do contexto, a ordem na autenticação, a taxa que escolhe o
escopo por pedido, os imports que o DRF faz no meio do próprio import).

**Todo critério roda no contêiner `worker`**, de `/repo/backend`. O atalho `W` é
`docker compose exec -T worker`. Critério **padrão** de toda tarefa, além do próprio:

```
W pytest tests ; W mypy ; W ruff check . ; W ruff format --check .
```

A suíte inteira leva ~15 min (1021 testes, medido em 2026-09-28). Durante a tarefa, rodar só
os arquivos que ela toca e `tests/accounts`; **a suíte inteira fecha a tarefa**, uma por vez
([aprendizados](../aprendizados.md), "Duas suítes no mesmo `worker`").

### O gerente — literal, porque a falha é silenciosa

```python
class OrganizationScopedManager(models.Manager[_M]):
    def get_queryset(self) -> models.QuerySet[_M]:
        organization_id = current_organization_id()
        if organization_id is None:
            raise OrganizationScopeMissing(f"{self.model.__name__} sem organizacao no contexto")
        field: str = getattr(self.model, "organization_field")
        return super().get_queryset().filter(**{field: organization_id})
```

Sem argumento no construtor (o acessor reverso o constrói sem argumento,
`related_descriptors.py:682` e `:724`); o `getattr` resolve o `mypy` estrito.

### A taxa — literal, porque o `SimpleRateThrottle` exige escopo no construtor

```python
class ApiRateThrottle(SimpleRateThrottle):
    def __init__(self) -> None:
        pass  # o escopo depende do pedido; o `SimpleRateThrottle.__init__` exigiria um fixo

    def allow_request(self, request: Request, view: APIView) -> bool:
        self.scope, self.ident = self._who(request)
        self.rate = self.get_rate()
        self.num_requests, self.duration = self.parse_rate(self.rate)
        return super().allow_request(request, view)

    def get_cache_key(self, request: Request, view: APIView) -> str:
        return self.cache_format % {"scope": self.scope, "ident": self.ident}
```

`_who` devolve `("api_key", f"key:{request.auth.prefix}")` quando `request.auth` é `ApiKey`,
`("user", f"user:{request.user.pk}")` com sessão, e `("anon", f"anon:{self.get_ident(request)}")`
senão. **`Request` e `APIView` só sob `TYPE_CHECKING`** (com `from __future__ import annotations`):
o módulo é importado no meio do import de `rest_framework.views`, antes de `APIView` existir (ver
*O que já foi medido*). Importar o modelo `ApiKey` no topo é seguro.
