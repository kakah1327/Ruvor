### Os trechos e a previsão do próximo pregão (RF-03, RF-03a) — literal, a falha é silenciosa

Com `R = 252`, `full = concat(train, test)`, `n_train = len(train)`, `n = len(test)`:

```python
def _chunk_starts(n: int) -> range:          # os inicios de trecho, inclusive o da posicao n
    return range(0, n + 1, R)                # n + 1: se n e multiplo de R, n abre um trecho

# o trecho que contem a posicao p (0 <= p <= n) comeca em (p // R) * R
# os parametros do trecho que comeca em s sao estimados com full.iloc[: n_train + s]
```

- `historical_mean`: no trecho que começa em `s`, `μ̂ = full.iloc[: n_train + s].mean()`; a previsão de cada posição
  `p` do trecho, e a da posição `n` se ela cair nele, é `μ̂`.
- `ar_1`: no trecho que começa em `s`, `known = full.iloc[: n_train + s]`; `y = known[1:]`, `X = [1, known[:-1]]`;
  `(ĉ, φ̂)` por `np.linalg.lstsq(X, y, rcond=None)`; a previsão da posição `p` é `ĉ + φ̂ · full.iloc[n_train + p − 1]` —
  **o retorno da véspera**, inclusive para `p = n`, em que é o retorno do `as_of_date` (`full.iloc[-1]`).
- **A posição `n` não é caso especial**: é calculada pelo mesmo laço, com o trecho `n // R`. Se `n % R == 0`, esse
  trecho começa em `n` e reestima com tudo até o `as_of_date`. A prova é o V-02 da T1: acrescentar qualquer retorno ao
  fim do teste e recalcular dá, no novo último dia, o `next_value` de antes.

### A estatística (RF-07, RF-08) — literal, a falha é silenciosa

```python
def newey_west_lag(n: int) -> int:
    return math.floor(4 * (n / 100) ** (2 / 9))           # 7 com n = 2240; 4 com n = 250

def long_run_variance(x: np.ndarray) -> float:
    n = len(x); c = x - x.mean(); L = newey_west_lag(n)
    v = float(c @ c) / n                                   # gamma_0, divisor n
    for k in range(1, L + 1):
        v += 2 * (1 - k / (L + 1)) * float(c[k:] @ c[:-k]) / n   # divisor n, nao n - k
    return v
```

- `e_ref = r`; `e = r − ŷ`. `mse = mean(e²)`, `mse_reference = mean(r²)`, `r2_os = 1 − mse / mse_reference`.
- **DM**: `d = r² − e²`; `V = long_run_variance(d)`; com `V > 0`, `dm_statistic = mean(d) / sqrt(V / n)` e
  `dm_p_value = 1 − Φ(dm_statistic)` (**unilateral**, `scipy.stats.norm.sf`); com `V ≤ 0`, os dois nulos.
- **CW**: `f = r² − (e² − ŷ²)`; o mesmo, com `f`.
- **Direção**: `m = (r != 0) & (ŷ != 0)`; `direction_days = m.sum()`; sem dia, os três nulos. `p_y = mean(r[m] > 0)`,
  `p_x = mean(ŷ[m] > 0)`, `hit_rate = mean((r[m] > 0) == (ŷ[m] > 0))`.
- **PT**, com `N = direction_days`, `P = hit_rate`:

  ```python
  p_star = p_y * p_x + (1 - p_y) * (1 - p_x)
  var_p = p_star * (1 - p_star) / N
  var_p_star = ((2*p_y - 1)**2 * p_x*(1 - p_x) / N
                + (2*p_x - 1)**2 * p_y*(1 - p_y) / N
                + 4 * p_y*p_x*(1 - p_y)*(1 - p_x) / N**2)
  # nulos se p_x em {0, 1}, p_y em {0, 1}, ou var_p - var_p_star <= 0
  pt_statistic = (P - p_star) / sqrt(var_p - var_p_star); pt_p_value = norm.sf(pt_statistic)
  ```
