## Como ler este plano

[PROCESSO §5](../PROCESSO.md#5-anatomia-de-um-plano): contratos, não corpos. Literal só onde é
contrato (colunas, `db_table`, o SQL do gatilho, as assinaturas, os nomes) ou onde a falha é
silenciosa (o booleano do CSV, o decimal, o gerente que precisa do queryset que recusa, a negociação
que ignora o `Accept`, a exceção do banco que envenena a transação do teste).

**Todo critério roda no contêiner `worker`**, de `/repo/backend`. O atalho `W` é
`docker compose exec -T worker`. Critério **padrão** de toda tarefa, além do próprio:

```
W pytest tests ; W mypy ; W ruff check . ; W ruff format --check .
```

A suíte inteira leva da ordem de 15 min. Durante a tarefa, rodar só os arquivos que ela toca e
`tests/accounts`; **a suíte inteira fecha a tarefa**, uma por vez
([aprendizados](../aprendizados.md), "Duas suítes no mesmo `worker` usam o mesmo banco de teste").

### Os bytes — literal, porque a falha é silenciosa

```python
def _decimal(value: Decimal | None) -> str | None:
    return None if value is None else format(value, "f")  # nunca str(): 0E-10

def _instant(value: datetime | None) -> str | None:
    return None if value is None else value.astimezone(UTC).isoformat()

def to_bytes(content: dict[str, Any]) -> bytes:
    return json.dumps(
        content, ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False
    ).encode("utf-8")
```

`to_bytes` não conhece `Decimal` nem `datetime`: `build_content` já os converteu. Um `Decimal`
esquecido levanta `TypeError` no `json.dumps`, e não vira `float` calado.

### A célula do CSV — literal, porque `bool` é `int`

```python
def _cell(value: object) -> str:
    if value is None:
        return ""
    if isinstance(value, bool):          # antes do int: True é int, e sairia "True"
        return "true" if value else "false"
    return str(value)                    # o texto do JSON (decimal) ou o inteiro
```

`to_csv` faz `json.loads(bytes(content))`, `csv.writer(buffer, lineterminator="\r\n")` sobre um
`io.StringIO`, o cabeçalho `CSV_FIELDS` e uma linha por item de `results`, e devolve
`buffer.getvalue().encode("utf-8")` — sem BOM.

### A negociação do download — literal

```python
class IgnoreClientContentNegotiation(BaseContentNegotiation):
    """O download nao depende do `Accept` (RF-08): o corpo e o `HttpResponse` da view, e o
    renderizador escolhido so serve ao corpo de erro, que continua JSON."""

    def select_parser(self, request, parsers):
        return next(iter(parsers))

    def select_renderer(self, request, renderers, format_suffix=None):
        renderer = next(iter(renderers))
        return (renderer, renderer.media_type)
```

As anotações de tipo seguem as dos `djangorestframework-stubs` para `BaseContentNegotiation`.
