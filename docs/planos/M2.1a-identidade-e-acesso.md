## Como ler este plano

[PROCESSO §5](../PROCESSO.md#5-anatomia-de-um-plano): contratos, não corpos. Literal só onde é
contrato (assinaturas dos serviços, `db_table`, colunas, escolhas, nomes das chaves do cache,
settings) ou onde a falha é silenciosa (a ordem das checagens, a trava do `last_admin`, a
restauração depois do `flush`, o bloqueio consultado antes da senha).

**Todo critério roda no contêiner `worker`**, de `/repo/backend` (o `WORKDIR`), sem `-w`. O
atalho `W` abaixo é:

```
docker compose exec -T worker
```

Exceção declarada: a checagem do `compose.yaml` (V-17), que não está montado no `worker`, roda no
hospedeiro.

Critério de aceite **padrão** de toda tarefa, além do próprio:

```
W pytest tests ; W mypy ; W ruff check . ; W ruff format --check .
```

A suíte inteira leva ~13 min (medido em 2026-09-27: `622 passed in 756.49s`). Durante a
tarefa, rodar só `W pytest tests/accounts tests/test_usuario.py tests/test_organizacao.py
tests/test_esquemas.py`; a suíte inteira fecha a tarefa.
